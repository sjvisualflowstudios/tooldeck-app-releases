# Tooldeck Online

Android app wrapper for https://www.tooldeck.online/
Generated by ToolDeck (https://www.tooldeck.online/website-to-apk).

## IMPORTANT: HOW TO UPLOAD TO GITHUB

1. Unzip this file.
2. Upload ALL of these files to a new private GitHub repository.
3. Go to your GitHub repository in your browser. Click **Add file** -> **Create new file**.
4. In the file name box, type exactly: **.github/workflows/build.yml**
5. Paste the YAML code provided on your ToolDeck website into the text box and click **Commit changes**.
6. Go to the **Actions** tab, click "Build signed APK", and click "Run workflow".
